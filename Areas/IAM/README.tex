\Needspace{5\baselineskip}\section*{Implementación disponible}
La aplicación exige OneLogin OIDC. La API SCIM Core 1 permite alta, consulta, actualización, suspensión y eliminación. El almacén comprueba cuenta activa y rol en cada operación, incluso si la sesión estaba abierta antes de un cambio. \textnormal{comprobar\_\allowbreak{}scim.py} verifica acceso anónimo rechazado y consulta con token correcto; no crea usuarios ni prueba el MFA por sí mismo.\par
\Needspace{5\baselineskip}\section*{1. Coordinar con TI}
Recibir APP\_BASE\_URL y SCIM\_TOKEN de la configuración local, mediante el canal privado. El secreto no se escribe en el plan, README, Issues ni evidencia. Crear el conector OIDC y el conector SCIM siguiendo la guía completa (04\_IAM\_OneLogin.pdf).\par
OIDC devuelve a \textnormal{APP\_\allowbreak{}BASE\_\allowbreak{}URL/\allowbreak{}auth/\allowbreak{}callback}. SCIM recibe en \textnormal{APP\_\allowbreak{}BASE\_\allowbreak{}URL/\allowbreak{}scim/\allowbreak{}v1}. Mantener la configuración del token endpoint compatible con el conector. Los parámetros Client ID, Client Secret y metadata URL los copia TI a \textnormal{.env}; nunca se configuran dentro del JavaScript del navegador.\par

\Needspace{5\baselineskip}\section*{3. Comprobar SCIM}
En el servidor TI, cargar \textnormal{.env} en una terminal privada; ejecutar el verificador desde el clon:\par
\Needspace{7\baselineskip}
\begin{Comandos}
set -a
source ~/lab-runtime/app/.env
set +a
python3 Areas/IAM/comprobar_scim.py --url https://REEMPLAZAR.trycloudflare.com
\end{Comandos}
Resultado esperado: anonimo 401, autorizado 200 y correcto true. El token se obtiene del entorno y no aparece en la línea de comando. No usar HTTP ni URLs con credenciales.\par
\Needspace{5\baselineskip}\section*{4. Alta automática}
\begin{enumerate}
\item RRHH entrega solicitud aprobada.
\item Crear el usuario OneLogin y configurar sus atributos.
\item Asignar el conector SCIM mediante la regla o mapping autorizado.
\item Confirmar el evento de aprovisionamiento y que la cuenta aparece en la aplicación, sin ejecutar un alta local manual.
\item Asignar el conector OIDC.
\item Registrar MFA y abrir una sesión nueva con desafío real.
\item Consultar y ejecutar mantenimiento con el ingeniero; guardar antes y después del contador.
\end{enumerate}
\Needspace{5\baselineskip}\section*{5. Cambio y baja}
Cambiar title a auditor desde OneLogin y confirmar SCIM\_UPDATE. Mantener la sesión anterior abierta: mantenimiento debe responder 403. Suspender el usuario o retirar la aplicación según la política del conector y confirmar active false o SCIM\_DELETE. Repetir con la sesión anterior y después con un inicio nuevo. Registrar tiempo de propagación y resultado efectivo.\par
Los tests HTTP usan una respuesta de proveedor simulada exclusivamente en pruebas para comprobar vínculo de identidad y permisos. El sistema que se despliega utiliza Authlib y OneLogin reales; no contiene un modo de login local.\par

Matriz de roles, configuración sin secretos, resultado del verificador, evidencias de aprovisionamiento/MFA/cambio/baja y referencias del evento. Las cuentas de OneLogin no se han creado desde aquí porque requieren el tenant y sus permisos.\par
